    02 Manifesto

    Terminals were built for institutions.
    So everyone else trades on screenshots.
    So we built one you can own.

    // what we believe

    A number without a source is a rumour. Every snapshot says live, delayed, cached or synthetic — and which provider served it.

    Blank beats invented. If a provider can't fill a metric, the cell says why instead of showing a plausible-looking guess.

    Your data stays on your machine. Self-hosted, MIT, local LLMs welcome. No telemetry, no seat licence.

    Analysis should end in action. Alert → paper order, screen → backtest, idea → out-of-sample verdict — in one shell.

    09 Questions

    Frequently asked.

    Something missing? Read the docs or open an issue.

    Is it really free?

    Yes. OpenTerminalUI is MIT-licensed and runs on your own hardware. The only costs are any paid data providers you choose to plug in.

    Do I need API keys to start?

    No. It runs on free sources (Yahoo, NSE, FXMacroData, FRED) out of the box. Keys for Kite, Finnhub, FMP or Alpaca unlock live ticks and deeper fundamentals, and can be added later from Settings → Data Providers.

    Which markets are covered?

    NSE, BSE, NYSE and NASDAQ equities, NSE and US options, plus crypto, forex, commodities, bonds, ETFs and mutual funds. Opening a symbol re-points the whole terminal to its market.

    How do I know whether a number is live?

    Every snapshot carries a provenance chip — LIVE, DELAYED, CACHED, SYNTHETIC or NO DATA — with the serving provider and as-of time. The status bar shows per-provider health.

    Can Claude or another agent use it?

    Yes. The built-in MCP server exposes 45 tools over stdio or HTTP. An API key maps to a user, read keys only reach read tools, and write tools only create proposals that you confirm.

    Does it place real trades?

    No. Orders go to the built-in paper-trading engine. The agent never executes anything — it proposes, you approve.

    Can I run the AI features locally?

    Yes. Point it at LM Studio (e.g. a Gemma model) for news sentiment and the agent, or use OpenRouter's free models. Nothing leaves your machine when you run locally.

    What does it need to run?

    Docker, or Python 3.11 and Node. 2 cores and 4 GB RAM is enough; SQLite by default, PostgreSQL and Redis optional.
