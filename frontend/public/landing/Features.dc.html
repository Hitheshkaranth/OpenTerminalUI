MOD-01 · UPDATED IN 0.8

Terminal shell

  • GO bar symbol & route lookup (Ctrl+G)
  • Command palette, 25+ functions (Ctrl+K)
  • Function keys F1–F9
  • Grouped nav rail with pins & recents
  • Symbol Context Rail on every symbol page
  • Terminal Noir, classic and light themes
MOD-02 · UPDATED IN 0.8

Data trust & providers

  • Provenance on every snapshot: live · delayed · cached · synthetic
  • Blank metrics say which provider would fill them
  • Per-provider health row in the status bar
  • Settings → Data Providers: set, mask, test, clear keys
  • Synthetic data labelled, never a price basis
  • Market follows the symbol you open
MOD-03

Charting

  • Up to 9 synced panels, linked crosshairs
  • 70+ technical indicators
  • 1m → 1M with extended hours
  • Drawing tools, volume profile, replay
  • Renko, Kagi, Point & Figure, Line Break
  • OpenScript; PNG / SVG / CSV export
MOD-04

Equity research

  • 8-tab Security Hub, US and India
  • Fundamentals, estimates, peers, ESG
  • Earnings calendar & surprises
  • Shareholding history, corporate actions
  • Insider monitor & cluster-buy detection
  • AI catalysts & conviction
MOD-05

Screener & stock picking

  • Query builder + custom formula engine
  • 15+ visualisation modes
  • Value / Momentum / Quality / Low-vol composite
  • Point-in-time fundamentals
  • “Why ranked” explanations
  • Presets, sharing, multi-market scans
MOD-06

AI research agent

  • Console on any screen (Ctrl/Cmd+J)
  • Tool-using loop, screen-aware
  • Bull vs bear debate → PM decision
  • Strategy Lab with out-of-sample checks
  • Memory, threads, reflections
  • OpenRouter, Gemini, OpenAI or LM Studio
MOD-07 · UPDATED IN 0.8

MCP for external agents

  • 45 tools over stdio or HTTP
  • API key → user: your portfolio, not a demo
  • Read keys see 38 read-only tools
  • 7 propose_* tools, human-confirmed
  • otui:// resources + 5 workflow prompts
  • {ok, data, provenance} on every result
